Projects

Rust, CUDA

paged-kv-cache

A KV-cache memory manager modeled on vLLM’s PagedAttention, written from scratch: a refcounted block allocator, per-sequence block tables with copy-on-write forking, prefix caching, and a continuous-batching scheduler with preemption. The core crate has no dependencies and runs on a CPU reference backend that doubles as the numerical oracle for the CUDA kernels.

With prefix caching on, a chat workload where most requests share a system prompt computes 69% fewer prompt tokens and nearly doubles the mean batch. The workspace has 130 tests, including randomized checks that every block’s refcount matches the block tables that point at it.

faultline

A fault-injection harness for tool-using LLM agents. A proxy between the agent and its tools injects rate limits, timeouts, truncated JSON, stale or subtly wrong data, and writes that commit but report failure. Each trial is graded on the state of the world the agent leaves behind rather than on what it says, and fault schedules are seeded so every architecture faces the same failures.

The scripted control sweep already shows the shape of the problem: client retries lift the pass rate under rate limiting from 50% to 94%, but do nothing for stale or wrong data, which reads back the same way every time.
