# sohamdutta.dev

Source for [sohamdutta.dev](https://sohamdutta.dev), served by GitHub Pages from `main`.

A single static page (`index.html`) with no build step and no JavaScript. The typeface is Source Serif 4, self-hosted in `fonts/` under the SIL Open Font License (`fonts/OFL.txt`).

To preview locally:

```bash
python3 -m http.server 8000   # then open http://localhost:8000
```
